# مستكشف عسير الذكي

تطبيق ويب عربي لاستكشاف الطبيعة والتراث والوجهات السياحية في منطقة عسير بالمملكة العربية السعودية. يجمع المشروع في واجهة واحدة صفحات لاستكشاف الأماكن، والخريطة، والتعرّف على الصور، والمرشد الذكي، واقتراح مسارات الرحلات.

> **حالة المشروع:** نموذج أولي للواجهة وتجربة الاستخدام. بعض الصفحات والأزرار توضيحية حالياً؛ خدمات الذكاء الاصطناعي والكاميرا والخرائط والموقع الجغرافي غير موصولة بخدمات فعلية بعد.

## روابط

- **التطبيق المنشور:** [smart-explorer-app.vercel.app](https://smart-explorer-app.vercel.app)
- **المستودع:** [x0ll/smart-explorer-app](https://github.com/x0ll/smart-explorer-app)

## ما الذي يقدمه؟

- **الرئيسية:** تصفح أماكن مميزة في عسير، مثل جبال السودة وقرية رجال ألمع ومنتزه عسير الوطني.
- **الخريطة:** واجهة مخصصة للبحث عن الأماكن واستكشافها؛ ربط مزود الخرائط والموقع الجغرافي يحتاج إلى تنفيذ.
- **التعرّف على الصور:** شاشة تمهيدية لالتقاط صورة أو اختيارها من المعرض بهدف التعرف على المعالم؛ التحليل الفعلي غير مفعّل حالياً.
- **المرشد الذكي:** واجهة محادثة وأسئلة مقترحة عن المنطقة؛ إرسال الرسائل إلى نموذج ذكاء اصطناعي يحتاج إلى تكامل لاحق.
- **التوصيات:** نموذج لمسار رحلة يومية يضم وجهات طبيعية في عسير.
- **واجهة عربية RTL:** تنقل سفلي مشترك وتصميم ملائم للشاشات الصغيرة.

## التقنيات

- Next.js 15 وReact 19 مع App Router
- TypeScript
- Tailwind CSS 4
- مكونات Radix UI وأيقونات Lucide

## التشغيل محلياً

يتطلب المشروع Node.js وpnpm.

```bash
 git clone https://github.com/x0ll/smart-explorer-app.git
cd smart-explorer-app
pnpm install
pnpm dev
```

افتح [http://localhost:3000](http://localhost:3000) في المتصفح.

أوامر أخرى:

```bash
pnpm build   # إنشاء نسخة الإنتاج
pnpm start   # تشغيل نسخة الإنتاج بعد البناء
pnpm lint    # فحص lint
```

## بنية المشروع

```text
app/
  page.tsx                 الصفحة الرئيسية
  camera/page.tsx          واجهة التعرف على الصور
  map/page.tsx             واجهة الخريطة
  guide/page.tsx           واجهة المرشد الذكي
  recommendations/page.tsx واجهة التوصيات
  layout.tsx               التخطيط العام والبيانات الوصفية
components/
  app-shell.tsx            الترويسة والتنقل المشترك
  ui/                      مكونات الواجهة
hooks/                     خطافات React مساعدة
lib/                       أدوات مشتركة
public/                    الصور والملفات الثابتة
```

## فرص التطوير

- ربط الخريطة بمزود خرائط وإضافة بيانات موثوقة للأماكن.
- تنفيذ تحديد الموقع بعد أخذ إذن المستخدم.
- تفعيل اختيار الصور والكاميرا وربطها بخدمة للتعرف على المعالم.
- ربط المرشد الذكي بمصدر معلومات موثوق عن عسير.
- استبدال التفاعلات التوضيحية الحالية بوظائف فعلية وإضافة اختبارات.
